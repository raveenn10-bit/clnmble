# Digitel Phone Market - Galle E-Commerce & Wholesale Platform 📱🇱🇰

A high-performance modern web application for **Digitel Phone Market (DPM)** — Wholesale & Retail dealers in Galle, Sri Lanka.

## 🌟 Highlights & Features

- **Digitel Phone Market Branding:** Designed to match the official Galle wholesale identity with deep royal blue accents (`#1D4ED8`), active handset logo, and clean typography.
- **2UUL Technician Tools Section:** Highlights technician hardware from the showroom (2UUL Preheat Puller, 130,000 RPM Cool Fan Vac Pro, Mini Sharpener, The One Jig PCB fixtures).
- **Comprehensive Product Catalog:** Smartphones, tablets, parts, and wholesale packs with accurate LKR pricing (`රු`).
- **Showroom Reviews:** Real customer and repair technician reviews in Sinhala & English for Galle showrooms and delivery hubs.
- **Interactive Quick View & Cart Drawer:** Hardware specifications, quantity controls, Free Islandwide Delivery threshold meter (LKR 15,000), and checkout simulator.
- **Galle Showroom Directory:** Addresses, phone hotline (`077 118 3979`), and Google Maps directions.
- **WhatsApp Support:** Instant WhatsApp ordering connected to `+94 77 118 3979`.
- **Mobile Bottom Navigation:** App-like sticky bottom bar on mobile screens.

## 🛠️ Tech Stack

- **React 18**
- **Vite 6**
- **Tailwind CSS 3**
- **Lucide Icons**

## 🏃 Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
